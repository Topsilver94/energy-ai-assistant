> **阅读时长**：约 3 分钟　|　**适用对象**：业务与招聘评估

## 一、一句话说明

把综合能源售前「客户初诊 → 能耗对标 → 系统配置 → 收益测算 → 方案成文」的全流程，**从 2–3 个工作日压缩到几分钟**——打开网页即用，无需安装、无需注册。

![演示模式三列同屏](screenshots/04-overview.png)

## 二、它解决什么业务问题

中小型综合能源集成商与独立能源顾问的真实困境：

| 痛点 | 具体表现 |
|---|---|
| 售前太重 | 一份像样的节能改造方案要 2–3 个工作日：查标准做对标、凑系数算收益、套模板拼文案 |
| 小商机被劝退 | 几十万级的项目，售前投入的时间成本高于预期利润，干脆不跟 |
| 一线够不着技术 | 销售在客户现场拿不到技术即时支持，问不出结论，商机当场冷掉 |
| 口径不统一 | 不同人算同一栋楼给出不同数字，客户一问来源就答不上来 |

**产品化解法——「先诊断后开方」**，让链路自然衔接，用户不需要提前想清楚"该装什么系统"：

```
首次接触客户能拿到的信息  →  STEP① 的输入（面积 / 电费 / 年份）
STEP① 推荐出的系统与规模   →  STEP② 的输入（这正是客户想问的）
STEP① + STEP② 的结构化结果 →  STEP③ 的输入（成文输出）
```

## 三、三步能力

### ① 挖掘痛点 —— 客户现场就能出结论

**录入**：建筑性质（既有 / 新建）、建筑类型、面积、省份；既有建筑另填年电费（支持按年 / 按月两种口径；留空时按典型强度或变压器容量双口径取短板预估，并在结果上明确标注"预估"）；可另选填变压器容量、屋面面积、车位数。

**输出**：
- 单位面积能耗对标（与同类型基准比高低）、节能潜力百分比
- 三条针对性技术建议
- **自动推导四类系统的建议规模**（分布式光伏 / 储能 / 集中供冷 / 充电桩），并给出每条的触发依据与置信度
- 一键填入 STEP② 并自动跳转

**业务价值**：客户现场报出面积和电费，当场就能回答「你这栋楼能耗偏高多少、建议上多大光伏配多大储能」。

![诊断页](screenshots/01-diagnosis.png)

### ② 锁定收益 —— 报价前先知道赚不赚钱

**录入**：系统组合（四类系统多选）× 各系统规模 × 省份。

**输出**：
- **组合总账**：总投资（万元）、IRR、投资回收期（年）、年碳减排（tCO₂）
- 分项明细表：每个系统的投资 / 收益 / 碳减排拆开看
- **敏感性分析**：电价 / 峰谷价差 / 利用小时 / 整体造价 四个变量，各按 ±10% / ±20% 重算，直接看"什么条件下这笔投资不成立"

**业务价值**：报价前先知道"赚多少、多久回本、哪个变量最要命"；也能独立用于投标测算或客户自带明确需求的场景。

![测算页](screenshots/02-calculator.png)

### ③ 订制方案 —— 一页纸交给客户

**输出**：自动汇总前两步的结构化数据，生成一页式《综合能源节能改造方案》——报告头 / 执行摘要 / 分项明细 / 敏感性结论 / 建设节奏建议 / 预期收益，**支持导出打印级 PDF**，也可复制正文。

**业务价值**：现场或会后直接递一页纸给客户，不必回去再排版。

![方案报告](screenshots/03-report.png)

## 四、为什么这些数字敢拿去见客户

这是本工具区别于"拍脑袋估算表"的三条底线：

**1. 每个系数都有出处**
电价、峰谷价差、分时结构、利用小时、电网排放因子、建筑能耗基准等全部集中在可查看可调的配置面板里，逐项标注来源等级（真实公开数据 / 政策口径 / 演示假设）与数据截止日期（当前截至 2026 年 9 月，按月 / 季分层换版）。客户问"这个电价哪来的"，点开就能答。

**2. 数字由确定性引擎算出，不是 AI 编的**
财务测算、系统定容、敏感性结论、建设节奏全部由规则引擎确定性派生——**同样的输入必得同样的输出**，可复算、可审计。AI 只负责把结论写成通顺的文字，**没有权限改动任何一个数字**。这是本工具对"AI 怎样安全进入商务材料"的回答。

**3. 不配 AI 也能完整走通**
未配置或调用失败时自动降级为本地模板生成，三步流程全程可用——核心业务不依赖大模型的可用性。

**4. 收益模型经过工程校准，不是粗算**
以储能为例：不是简单的"容量 × 365 天满充满放"，而是计入充放电效率、放电深度、全年可用天数、分省分时结构（一充一放 / 两充两放）；对执行两部制电价的用户，按政策门槛计入需量管理削峰收益。口径边界（代理购电固定分时 vs 市场化用户）在报告中明确注明，不做模糊处理。

**数据覆盖面**：31 个省级行政区（电价 / 峰谷价差 / 分时结构 / 利用小时 / 排放因子）× 7 类建筑能耗基准（办公 / 商场 / 医院 / 酒店 / 高校 / 数据中心 / 工业厂房）× 4 类系统。

## 五、3 分钟看全流程

1. 打开 https://topsilver94.github.io/energy-ai-assistant/
2. **STEP①** 填：既有办公建筑 / 20000 ㎡ / 年电费 200 万 → 点「开始诊断」→ 看能耗对标、节能潜力与四类系统的推荐规模
3. 点「填入模块②」→ 参数自动带入并跳转
4. **STEP②** 点「开始测算」→ 看组合总账、分项明细、敏感性分析
5. **STEP③** 点「生成方案报告」→ 未填 Key 会立即生成完整报告（本地模板）→ 点「导出 PDF」得到可打印的一页纸
6. 右下角可切换 **演示模式**（三列同屏看全貌）/ **工作模式**（分步专注操作）

> 想体验 AI 流式成文：右上角「API 设置」填入自己的 GLM / DeepSeek Key 即可（Key 仅存于内存，不写入本地、不上传）。

## 六、边界与诚实声明

- 这是一个**演示型工具**，不是生产系统：不接后台、不存数据、不做多人协作，刷新即清空
- 部分工程经验系数为**演示假设值**（面板中已按来源分级如实标注），实际商用需按项目实测数据替换
- 财务口径边界：储能套利按代理购电固定分时测算，市场化用户需按现货价差重估——**报告内已明确注明**，不掩盖假设
- 新建建筑不输出"节能潜力%"：没有实际能耗基线就不编造数据
